ЖИВ ПОМОЩНИК - "кое ми трябва" (версия 2, 25.10.2026)

Какво е: плаващ бутон "Кое ми трябва?" на всички страници на alive-garden.com.
Посетителят описва проблема, помощникът препоръчва книга, карта или комплект с линк.
Не дава рецепти и дозировки - казва къде са описани (карта / глава).

ЧАСТИ
- server.js      - сървърът (Render: https://zhiv-pomoshnik.onrender.com)
- knowledge.md   - всичко, което помощникът знае. Само проверени факти.
                   При нова цена, нов продукт или нов бонус: смени тук и качи наново.
- widget.html    - кодът за ConvertBuilder (бутон + чат прозорец)
- test-questions.mjs - 12 реални въпроса за проверка след всяка промяна

1. КАЧВАНЕ НА СЪРВЪРА (Render)
- Файловете отиват в GitHub repo deyanivanovbg-ship-it/zhiv-pomoshnik
- Render: Build command = npm install, Start command = node server.js
- Environment: ANTHROPIC_API_KEY (вече е там). По желание GLOBAL_DAY = таван въпроси на ден (по подразбиране 1500)
- Проверка: node test-questions.mjs

2. ПОСТАВЯНЕ В САЙТА (ConvertBuilder, deyanivanovbg-8)
- Целият widget.html в общия код на сайта (Custom Body Markup), за да е навсякъде.
  Ако общото поле не обхваща фуниите - в Custom Code на всяка фуния (Body).
- Сам се скрива на чекаути, ъпсели, благодарствени и правни страници.
- Сам маха стария бутон "Жив Помощник". Старият Code елемент на /zhiva-gradina може да се изтрие.

ЛИМИТИ (в server.js)
- 20 въпроса на час и 50 на ден от един човек, 1500 общо на ден
- Работи само от alive-garden.com (от други сайтове - отказ)
- Модел: claude-sonnet-5-5, кратки отговори, кеш на знанията

РЕНДЪР БЕЗПЛАТЕН ПЛАН
- Безплатният план заспива, когато няма трафик; първият въпрос след това чака по-дълго.
  Бутонът го събужда, когато някой отвори чата. Ако е твърде бавно - платеният план не заспива (провери цената в Render).

ЗАПИСВАНЕ НА ВЪПРОСИТЕ (от 27.10.2026, версия 2.1)
- Всеки въпрос се записва в логовете на Render като ред "въпрос {...}": време, кой поред въпрос е в разговора,
  въпросът, първият въпрос (ако е уточнение), препоръчаните линкове и отговорът.
- БЕЗ IP. Телефони и имейли в текста се заменят с [телефон] / [имейл].
- Render пази логовете 7 дни (безплатен план). За постоянен запис: Google Sheet по указанията в log-sheet.gs
  и променлива LOG_WEBHOOK_URL в Render. Без нея всичко работи, само записът е временен.
- Проверка на версията: https://zhiv-pomoshnik.onrender.com показва "version".
